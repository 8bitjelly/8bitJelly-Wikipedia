# Jak sklonować repozytorium przez GitHub Desktop?
### Prosty poradnik krok po kroku dla osób nietechnicznych

---

## 1. Pobierz i zainstaluj program
* Wejdź na oficjalną stronę: [desktop.github.com](https://desktop.github.com) i kliknij **Download**.
* Zainstaluj aplikację na komputerze.
* Przy pierwszym uruchomieniu możesz zalogować się swoim kontem GitHub lub wybrać opcję pominięcia (*Skip this step*).

---

## 2. Skopiuj link do repozytorium
* Otwórz stronę wybranego projektu na GitHubie w przeglądarce internetowej.
* Kliknij zielony przycisk **`<> Code`** (znajduje się po prawej stronie, tuż nad listą plików).
* Upewnij się, że wybrana jest zakładka **HTTPS**.
* Kliknij ikonę kopiowania (dwa nakładające się kwadraciki) obok adresu URL.

---

## 3. Sklonuj projekt w GitHub Desktop
* Otwórz aplikację **GitHub Desktop**.
* W górnym menu wybierz: **`File` ➔ `Clone repository...`**  
  *(lub użyj skrótu: `Ctrl + Shift + O` na Windows / `Cmd + Shift + O` na Macu)*.
* W okienku, które się otworzy, przejdź do zakładki **`URL`** (po prawej stronie).
* Wklej skopiowany adres w pierwsze pole (**URL or username/repository**).
* W dolnym polu (**Local path**) kliknij **`Choose...`** i wskaż folder na dysku, w którym chcesz zapisać projekt.
* Kliknij niebieski przycisk **`Clone`**.

---

## 4. Gotowe! Jak pobierać aktualizacje w przyszłości?
Gdy autor projektu wprowadzi zmiany lub doda nowe pliki:
1. Otwórz **GitHub Desktop**.
2. Upewnij się, że w lewym górnym rogu (*Current repository*) wybrany jest Twój projekt.
3. Kliknij przycisk **`Fetch origin`** (a następnie **`Pull origin`**) na górnym pasku.
4. Wszystkie nowe pliki zaktualizują się automatycznie na Twoim dysku!
